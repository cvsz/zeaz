# คู่มือแบรนด์ MooPiew

| องค์ประกอบ | แนวทาง |
| --- | --- |
| ชื่อ | MooPiew / หมูปิ้ววว |
| คำมั่นสัญญา | หมูย่างถ่านหอมอุ่น พร้อมตามเวลาที่ลูกค้าต้องการ |
| น้ำเสียง | เป็นกันเอง ตรงไปตรงมา น่ากิน และน่าเชื่อถือ |
| สีหลัก | `#FF6B35` |
| สีเข้ม | `#111827` |
| ตัวอักษร | Inter ExtraBold สำหรับ display และฟอนต์ไทยที่อ่านง่ายสำหรับเนื้อหา |

ใช้ SVG หลักใน `assets/branding/logo/` และใช้ภาพหมูปิ้งจริงที่ได้รับอนุมัติสำหรับภาพ header/hero
โดยวาง overlay ให้ข้อความอ่านง่าย ห้ามสื่อราคา เวลาเปิด หรือพื้นที่ส่งที่ไม่เป็นจริง

ทรัพย์สินแบรนด์เป็นกรรมสิทธิ์ของ MooPiew ไฟล์ต้นฉบับและ artwork ของพาร์ตเนอร์ห้ามใส่ใน release สาธารณะ
