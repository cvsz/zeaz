# คู่มือปฏิบัติงาน

## Checklist ก่อนเปิด

- ตรวจสถานที่ อุปกรณ์ความปลอดภัย และสต็อก
- ยืนยันตารางพนักงาน งานสำคัญ และออเดอร์/การจอง
- เตรียมจุดทำงานและบันทึกปัญหาใน shift log

## ขั้นตอนบริการ

1. ทักทาย ทำความเข้าใจความต้องการ และยืนยันราคา/เวลา
2. ผลิตหรือให้บริการตามมาตรฐาน
3. ตรวจคุณภาพก่อนส่งมอบ และแก้ปัญหาทันที
4. บันทึกยอดขาย ของเสีย และ feedback ตอนปิดร้าน

## Checklist ปิดงาน

- กระทบยอดเงินสดและการชำระดิจิทัล
- ทำความสะอาด เก็บสต็อก และเตรียมรายการสั่งซื้อ
- บันทึกงานซ่อม เหตุการณ์ และเรื่องสำคัญของวันถัดไป
