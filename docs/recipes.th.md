# คู่มือปฏิบัติงาน MooPiew

## ก่อนเปิด

- ตรวจความปลอดภัยอาหาร เตาย่าง/ถ่าน บรรจุภัณฑ์ และสต็อกที่พร้อมขาย
- ยืนยันเมนู เวลาเปิด ระยะส่ง และไรเดอร์ที่พร้อมรับงาน
- ตรวจออเดอร์ค้าง ใบสมัครไรเดอร์ และใบสมัครร้านค้า

## ออเดอร์และการส่ง

1. ตรวจเลขอ้างอิง รายการสินค้า วิธีรับสินค้า และสถานะชำระเงิน
2. เตรียมตามมาตรฐานอาหาร และเปลี่ยนเป็นพร้อมส่งมอบเมื่อพร้อมจริง
3. งานส่งให้มอบหมายไรเดอร์ที่ตรวจแล้วและ active แล้วอัปเดตตามสถานะจริง
4. งานรับที่ร้านให้จับคู่การส่งมอบกับเลขอ้างอิงของลูกค้า
5. ปิดออเดอร์เพียงครั้งเดียว ของเสีย/ปรับสต็อกให้บันทึกแยกพร้อมเหตุผล

## ปิดวัน

- กระทบยอดเงินสดและการชำระดิจิทัลที่อนุมัติกับออเดอร์สำเร็จ
- ทบทวนงานส่งล้มเหลว/ยกเลิกและการดูแลลูกค้า
- นับสต็อกสำคัญ ทำความสะอาด เก็บพื้นที่ และสำรองฐานข้อมูล
