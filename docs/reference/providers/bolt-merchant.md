# Bolt merchant registration — Thailand

Bolt's public Thailand driver pages do not publish a stable Thai Bolt Food
merchant document checklist. The system therefore exposes the merchant
service and business-type model, but keeps the requirement list empty until
Bolt supplies the current partner onboarding checklist.

Collect business type (individual/company/restaurant/cloud kitchen/cafe/retail/grocery),
owner identity, legal/business registration, tax, bank, store address, menu,
food licence and alcohol licence only when applicable. Mark each item as
provider-confirmed before making it required. Review is pending until Bolt
confirms the application.

Reference: https://bolt.eu/en-th/driver/ (provider portal/service context).
