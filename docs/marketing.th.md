# แผนการตลาด MooPiew

## Positioning

MooPiew ให้หมูย่างถ่านอุ่น ๆ และวิธีสั่งรับ/ส่งในพื้นที่ใกล้ร้านที่ง่ายและไว้ใจได้
สื่อสารเฉพาะเมนู เวลาเปิด พื้นที่ส่ง และราคาที่เปิดใช้งานจริงเท่านั้น

## วงจรเปิดตัว

1. เผยแพร่ลิงก์สั่งซื้อ สถานที่/พื้นที่ส่ง เวลาเปิด เมนู และภาพอาหารจริงพร้อมข้อความไทยที่อ่านง่าย
2. ใช้ข้อเสนอระยะสั้นที่มีเงื่อนไขคูปองอนุมัติโดยเจ้าของ
3. ขอ feedback หลังออเดอร์สำเร็จ ไม่ใช่ก่อนส่งมอบ
4. ทบทวน reach, conversion, การซื้อซ้ำ, ตะกร้าเฉลี่ย, การยกเลิก และความตรงเวลาส่งทุกสัปดาห์

## เสาหลักเนื้อหา

- หลักฐานสินค้า: การย่างจริง วัตถุดิบ และเมนูที่ขายอยู่
- ความสะดวก: เวลารับ พื้นที่ส่งที่ชัดเจน และ tracking ออเดอร์
- ความน่าเชื่อถือ: ความสะอาด การตอบสนอง และ feedback ที่ยืนยันได้

ห้ามเผยแพร่ที่อยู่/เบอร์ลูกค้า ตำแหน่งไรเดอร์ เลขอ้างอิงการจ่าย หรือการอ้างพาร์ตเนอร์ที่ยังไม่อนุมัติ
