# แผนธุรกิจการดำเนินงาน MooPiew

## ภาพรวม

| รายการ | แนวทางปัจจุบัน |
| --- | --- |
| แบรนด์ | MooPiew / หมูปิ้ววว |
| สินค้า | หมูย่างถ่าน ข้าวเหนียว และการสั่งรับ/จัดส่ง |
| ลูกค้า | ลูกค้าใกล้ร้านที่ต้องการอาหารไทยรวดเร็วและไว้ใจได้ |
| ช่องทาง | หน้าร้าน การส่งที่เจ้าของดูแล และพาร์ตเนอร์ที่อนุมัติ |

## รูปแบบการดำเนินงาน

ดูแล master data เวลาเปิด พื้นที่ส่ง เมนูพร้อมขาย และกำลังไรเดอร์ให้เป็นปัจจุบัน ราคา ค่าส่ง และโปรโมชัน
ต้องมาจากข้อมูลที่อนุมัติ ไม่ใช่ข้อความใน artwork ตรวจเรื่องผู้ขาย ความปลอดภัยอาหาร ภาษี แรงงาน และการส่งกับผู้เชี่ยวชาญในพื้นที่

## การเงินและตัวชี้วัด

ทบทวนยอดขาย กำไรต่อรายการ ส่วนต่างค่าส่ง การยกเลิก ของเสีย การใช้งานไรเดอร์ การซื้อซ้ำ และการกระทบยอดทุกวัน
ไฟล์การเงินเป็นเครื่องมือวางแผน ไม่ใช่คำแนะนำบัญชีหรือภาษี

## 90 วันแรก

1. ยืนยันคุณภาพสินค้า กำลังการผลิตช่วงเร่งด่วน และระยะส่ง
2. วัดการซื้อซ้ำ แล้วขยายจากพื้นที่เล็กที่ให้บริการได้สม่ำเสมอก่อน
3. รับพาร์ตเนอร์หลังตรวจร้าน/ไรเดอร์และตกลงเงื่อนไข settlement ชัดเจน
