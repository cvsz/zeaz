# แบบร่างแผนธุรกิจ

## ข้อมูลสรุป

| รายการ | การตัดสินใจ |
| --- | --- |
| ชื่อธุรกิจ | `{{BUSINESS_NAME}}` |
| ประเภทธุรกิจ | `{{CATEGORY}}` |
| สถานที่ | `{{LOCATION}}` |
| ลูกค้าเป้าหมาย | `{{TARGET_CUSTOMER}}` |

## ข้อเสนอและคุณค่า

อธิบายปัญหาของลูกค้า สินค้า/บริการหลัก ช่วงราคา และเหตุผลที่ลูกค้าควรเลือกเรา
ควรทดสอบข้อความนี้กับลูกค้าจริงก่อนเปิดกิจการ

## รูปแบบการดำเนินงาน

กำหนดเวลาเปิดทำการ ผู้ขาย อุปกรณ์ บทบาทพนักงาน กำลังการผลิต และรายการตรวจคุณภาพรายวัน

## การเงิน

บันทึกค่าเริ่มต้น ค่าใช้จ่ายประจำต่อเดือน กำไรขั้นต้น และยอดขายคุ้มทุน โดยใช้
`excel/financial-model.csv` เป็นโครงเริ่มต้น และตรวจสอบภาษี ใบอนุญาต และกฎหมายแรงงานในพื้นที่

## แผนเปิดตัว 90 วัน

1. ยืนยันความต้องการด้วยการคุยกับลูกค้า 10 คนและทดลองขายจริง
2. สรุป supplier ราคา ใบอนุญาต และ checklist
3. เปิดตัวแบบจำกัด เก็บ feedback และทบทวนตัวเลขทุกสัปดาห์
