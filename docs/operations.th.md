# คู่มือปฏิบัติการ — หมูปิ้ววว Pre-order

## เปิดระบบ

1. ตั้ง `ADMIN_KEY` เป็นรหัสผ่านที่ไม่ซ้ำกับระบบอื่น
2. รัน `./scripts/start.sh`
3. ทดสอบสั่ง 1 ออเดอร์จากหน้าเว็บ และเปิด `/admin.html` เพื่อตรวจสอบ

## รอบการทำงาน

- เปิดหน้าแอดมินก่อนเตรียมสินค้า เปลี่ยนออเดอร์เป็น `confirmed`
- เมื่อแพ็กเสร็จ เปลี่ยนเป็น `ready`; เมื่อรับสินค้าแล้วเปลี่ยนเป็น `completed`
- ยกเลิกเฉพาะเมื่อแจ้งลูกค้าแล้ว และบันทึกสาเหตุไว้ในช่องหมายเหตุของ order ถ้าจำเป็น

## การตั้งค่าเมนูและคิว

หน้าแอดมินสามารถเพิ่มเมนู ปิดขายชั่วคราว กำหนดจำนวนสินค้าสูงสุดต่อรอบ และจำนวนวันรับ
pre-order ล่วงหน้าได้ การเปลี่ยนแปลงถูกเก็บใน `data/settings.json` และไม่กระทบออเดอร์เก่า

ลูกค้าตรวจสอบหรือยกเลิกออเดอร์เองได้จากเลขที่ออเดอร์และเบอร์โทรศัพท์ เฉพาะสถานะ `new`
และ `confirmed` เท่านั้น; เมื่อยกเลิกแล้ว ความจุของรอบนั้นจะคืนทันที

## ข้อมูลและความปลอดภัย

ข้อมูล order อยู่ที่ `data/orders.json`; สำรองไฟล์นี้อย่างสม่ำเสมอและจำกัดสิทธิ์เข้าถึง
ระบบนี้เป็นจุดเริ่มต้นสำหรับใช้งานภายใน ไม่ควรเปิดสู่สาธารณะโดยไม่มี HTTPS, ฐานข้อมูล,
rate limiting, ระบบยืนยันตัวตน และนโยบายคุ้มครองข้อมูลส่วนบุคคลที่เหมาะสม
