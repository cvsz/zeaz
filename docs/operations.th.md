# คู่มือการปฏิบัติงานสำหรับเจ้าของร้าน

เปิด `/ops.html` ด้วย `X-Admin-Key` ของบริการ กุญแจนี้เป็นความลับของเจ้าของ ห้ามใส่ใน
หน้าเว็บสาธารณะ URL ภาพหน้าจอ หรือ Git

## ตั้งค่าครั้งแรก

1. กรอกข้อมูลกิจการให้ครบก่อนออกใบกำกับภาษี
2. ตั้งพิกัดร้าน ค่าส่งตั้งต้น ค่าต่อกิโลเมตร ระยะสูงสุด และโซนจัดส่ง ระบบคำนวณค่าส่งที่ฝั่งเซิร์ฟเวอร์
3. ตั้งเมนูและลำดับแสดงผล แล้วเพิ่มวัตถุดิบ/สูตรสำหรับรายการที่ต้องตัดสต็อกอัตโนมัติ
4. ตรวจใบสมัครไรเดอร์และร้านค้าให้ครบก่อนอนุมัติ และเปิดใช้งานไรเดอร์แยกต่างหาก
5. สร้างคูปองเมื่อมีเจ้าของแคมเปญ เงื่อนไข และวันหมดอายุชัดเจน

ไฟล์ `templates/store-master-data.json` ที่กรอกจริงอาจมีพิกัด เบอร์ติดต่อ หรือข้อมูลภาษี
จึงต้องเก็บไว้ในเครื่องและห้าม commit

## งานประจำวัน

1. ติดตามออเดอร์ใหม่และตรวจสถานะการชำระเงินตามช่องทางที่เลือก
2. งานส่งมอบให้มอบหมายไรเดอร์ที่ active/available แล้วเปลี่ยนสถานะตามลำดับ
   `queued` → `assigned` → `picked_up` → `on_the_way` → `delivered`
3. งานรับที่ร้านให้ตรวจเลขอ้างอิงก่อนส่งมอบ
4. ปิดออเดอร์เพียงครั้งเดียว เพื่อให้แต้มและสต็อกเคลื่อนไหวอย่างถูกต้อง
5. ออกใบเสร็จหรือใบกำกับภาษีจากออเดอร์ที่ยืนยันแล้วเท่านั้น

การยกเลิกเป็นกรณีพิเศษ เพราะคูปองและแต้มที่เข้าเงื่อนไขจะคืนได้เพียงครั้งเดียว

## ค่าส่งและการติดตาม

ค่าส่งตามระยะทางตั้งค่าได้เป็น `ceil(ค่าตั้งต้น + ค่าต่อกม. × ระยะที่คำนวณ)` ภายใต้ระยะสูงสุด
ถ้าไม่มีพิกัดร้านหรือลูกค้าเกินระยะ ระบบต้องไม่อนุญาตให้สั่งส่ง Tracking ใช้รหัสติดตามและ
อัปเดตแบบเรียลไทม์ แต่ไม่เปิดเผยที่อยู่หรือเบอร์ลูกค้า

## การชำระเงินและปิดวัน

SCB QR/EASY ต้องปิดไว้จนกว่าจะผ่านการอนุมัติ Sandbox, ตรวจสอบ Transaction Inquiry และมี
credential/certificate ถูกต้อง QR ที่สแกนหรือ callback เพียงอย่างเดียวไม่ใช่หลักฐานการจ่ายเงิน

เมื่อปิดวันให้กระทบยอด ตรวจงานส่ง/ไรเดอร์ นับสต็อกสำคัญ บันทึกปรับสต็อกอย่างตรวจสอบได้
รัน `./scripts/backup-database.sh` และตรวจ audit log.
