# MooPiew brand guide

| Element | Direction |
| --- | --- |
| Name | MooPiew / หมูปิ้ววว |
| Promise | Warm charcoal-grilled pork, ready when the customer needs it. |
| Voice | Friendly, direct, appetising and trustworthy. |
| Primary colour | `#FF6B35` |
| Dark ink | `#111827` |
| Typography | Inter ExtraBold for display; Thai-capable body type for Thai copy. |

Use the canonical SVG assets under `assets/branding/logo/`. Use real approved
food photography for hero/header imagery; preserve legibility with an overlay
and do not add misleading price, availability or delivery claims.

Brand assets are proprietary. Keep editable source files and partner-specific
artwork out of public release archives unless explicitly approved.
