Product promise

Private AI

Useful, optional and understandable.

AI processing is tiered between on-device execution, an approved enterprise cloud and explicitly enabled public-cloud services.

Tier 1

On-device

Rewriting, summarisation, transcription, translation, document classification, search, OCR and sensitive-data detection.

Tier 2

Private enterprise cloud

Organisation-approved endpoints with administrator control, defined retention and audit logging.

Tier 3

User-approved public cloud

Clear provider identity, explicit consent, sensitive-data warnings and reduced local functionality whenever possible.
