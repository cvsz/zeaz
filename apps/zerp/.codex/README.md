# ZERP Codex state

This directory is reserved for machine-readable, non-secret Codex audit state described by `../CODEX-MEGA-MAX-PROMPTS.md`.

Allowed tracked content must be deterministic, reviewable, free of credentials and personal data, and useful for reproducing repository audits. Runtime caches, transcripts, tokens, local paths, and ephemeral agent state must remain untracked.
